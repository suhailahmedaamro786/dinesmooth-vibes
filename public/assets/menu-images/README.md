# D-Pizza Menu Image Library

Folder structure:
- regular-items/ — 23 regular menu images
- deals/main-deals/ — active Main Deal 01-20 images (Deal 19 removed)
- deals/special-deals/ — Special Deal 01-21 images
- deals/event-deals/ — supper/event deal images

Total target: 70 final menu/deal images.

Important:
- Use JPG/WEBP images only, preferably compressed and consistent square 1:1 food photography.
- Do not put prices, text, logos, or watermarks inside food images.
- Do not upload duplicate images under different item names unless the same food is intentionally shared.
- Pizza size variants can share one pizza image.
